## Day 19 – Prime Number Checker-python ##

## Problem Statement ##

Given a number, determine whether it is a prime number or not.

## Approach ##

Check whether the number is divisible by any integer from "2" up
to its square root. If it is divisible by any of them, it is not prime. 
Otherwise, the number is prime.

## Complexity Analysis ##

- Time Complexity: "O(√n)"
- Space Complexity: "O(1)"
