Count Vowels and Consonants- Python 
## Problem Statement

Given a string, count the number of vowels 
and consonants in it.

## Approach

Traverse the string character by character. 
Check if each character is a vowel; otherwise, 
if it is an alphabet, count it as a consonant.

## Complexity Analysis

- **Time Complexity:** O(n)
- **Space Complexity:** O(1)
