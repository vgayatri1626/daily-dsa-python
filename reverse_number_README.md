🚀 Day 21 – Reverse an Integer
📌 Problem Statement
Given an integer, reverse its digits and return the reversed number.
💡 Approach
Extract the last digit using the modulus operator % and add it to the reversed number. Remove the last digit from the original number using integer division //. Repeat until all digits are processed.
⏱️ Complexity Analysis
Time Complexity: O(d)
Space Complexity: O(1)
