Best Time to Buy and Sell Stock

Difficulty: Easy

Problem: * Given an array of stock prices where each value represents 
         the price of a stock on a particular day, find the maximum 
         profit you can make by buying on one day and selling on a 
         future day *

Approach: Used a variable to track the minimum buying price seen so far. 
          For each day's price, calculated the possible profit and updated 
          the maximum profit if a better result was found.

Time Complexity: O(n)
Space Complexity: O(1)
