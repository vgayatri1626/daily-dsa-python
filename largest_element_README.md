# 🚀 Day 26 – Find the Largest Element

## 📌 Problem Statement

Given an array of integers, find the largest element in the array.

## 💡 Approach

Start with the first element as the largest. Traverse the array and compare each element with the current largest value. Update it whenever a larger element is found.

## ⏱️ Complexity Analysis

- Time: `O(n)`
- Space: `O(1)`
