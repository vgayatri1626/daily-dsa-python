# 🚀 Day 23 – Sum of Digits

## 📌 Problem Statement

Given an integer, find the sum of all its digits.

## 💡 Approach

Use `% 10` to extract the last digit and `// 10` to remove the last digit. Repeat until the number becomes 0.

## ⏱️ Complexity Analysis

- Time: `O(d)`
- Space: `O(1)`

Where `d` is the number of digits.
