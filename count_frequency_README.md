## Day 15 – Count Frequency of Elements-python ##

## Problem Statement ##

Given an array of integers, count the number of
times each element appears in the array.

## Approach ##

Use a Dictionary to store each number as a key 
and its frequency as the value.
Traverse the array and:
- If the number already exists in the dictionary, i
- ncrease its count.
- Otherwise, add it with a frequency of "1".

## Complexity Analysis ##

- Time Complexity: "O(n)"
- Space Complexity: "O(n)"
