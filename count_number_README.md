# 🚀 Day 24 – Count the Number of Digits

## 📌 Problem Statement

Given an integer, count the number of digits it contains.

## 💡 Approach

Repeatedly divide the number by `10` using `//` and increase the count until the number becomes `0`.

## ⏱️ Complexity Analysis

- Time: `O(d)`
- Space: `O(1)`

Where `d` is the number of digits.
