# Day 9 - First Non-Repeating Character

## Problem Statement

Given a string, find the first character that appears only once.

## Approach

Use a **Hash Map (Dictionary)** to count the frequency of 
each character. Traverse the string again and return the 
first character whose frequency is `1`.

## Complexity Analysis

- **Time Complexity:** O(n)
- **Space Complexity:** O(n)
