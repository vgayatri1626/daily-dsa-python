## Day 20 – Armstrong Number-python ##

## Problem Statement ##

Given a number, determine whether it is an Armstrong number or not.
## Approach ##

Convert the number into digits and calculate the sum of each digit 
raised to the power of the total number of digits. If the calculated 
sum is equal to the original number, it is an Armstrong number.

## Complexity Analysis ##

Time Complexity: O(d)
Space Complexity: O(d)
