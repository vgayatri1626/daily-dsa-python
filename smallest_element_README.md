# 🚀 Day 27 – Find the Smallest Element

## 📌 Problem Statement

Given an array of integers, find the smallest element in the array.

## 💡 Approach

Start with the first element as the smallest. Traverse the array and compare each element with the current smallest value. Update it whenever a smaller element is found.

## ⏱️ Complexity Analysis

- Time: `O(n)`
- Space: `O(1)`
