# 🚀 Day 25 – Sum of Even Numbers

## 📌 Problem Statement

Given an array of integers, find the sum of all even numbers in the array.

## 💡 Approach

Traverse the array and check each number using `% 2`. If the remainder is `0`, add the number to the total.

## ⏱️ Complexity Analysis

- Time: `O(n)`
- Space: `O(1)`
