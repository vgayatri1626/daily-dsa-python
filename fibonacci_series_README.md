🚀 Day 18 – Fibonacci Series

📌 Problem Statement

Given a number "n", print the first "n" terms of the Fibonacci series, where each term is the sum of the previous two terms.

💡 Approach

Start with two variables, "a = 0" and "b = 1". In each iteration, print the current value and update the two variables to generate the next Fibonacci number.

⏱️ Complexity Analysis

- Time Complexity: "O(n)"
- Space Complexity: "O(1)"
