Palindrome Check - Python

## Problem Statement
Given a string, determine whether it reads the same 
forward and backward.

## Approach
Use the **Two Pointers** technique. Start one pointer from 
the beginning and another from the end, compare the characters, 
and move both pointers toward the center.

## Complexity Analysis
- **Time Complexity:** O(n)
- **Space Complexity:** O(1)
